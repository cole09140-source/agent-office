## 알려진 한계 (실기기에서 확인 필요)
1. **GPU별 렌더링 차이**: SwiftShader에서만 검증. Mali·Adreno·Apple GPU에서 그레인·할레이션이 의도대로 보이는지 확인
2. **기울기 회전 방향**: deviceorientation 부호 규약을 표준 기준으로 구현. iOS·Android 실기기에서 좌·우 가로 촬영 각 1회 확인. 틀리면 `src/camera/orientation.ts`의 `quarterTurnsFor` 반환값 1↔3 교체
3. **네이티브 공유/저장**: Capacitor Share·Filesystem 경로는 빌드만 검증됐고 기기 실행은 미검증
4. **토치**: 실제 후면 플래시가 지원되는 기기(주로 Android Chrome)에서만 동작. iOS 웹뷰는 토치 API가 없어 플래시 룩(현상 효과)만 적용

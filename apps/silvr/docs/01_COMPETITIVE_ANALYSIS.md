## 3. 시장 공백 (Insight)

1. **"필름 경험"과 "필름 표현" 중 하나만 한다.** Gudak·Dispo는 기다림(경험)은 주지만 필름 선택·화질이 빈약하고, Dazz·VSCO는 표현은 풍부하지만 롤/현상의 설렘이 없다.
2. **찍은 뒤에 되돌릴 수 없다.** 대부분 촬영 시점에 필터가 "구워져" 저장된다. 필름이 마음에 안 들면 끝.
3. **필름의 물리적 변수(증감현상, 만료, ISO별 입자)를 제대로 다루는 앱이 없다.** 프리셋 이름만 다를 뿐 슬라이더는 일반 보정 앱과 동일.
4. **실제 필름 사용자(입문자 다수)를 위한 도구는 별도 앱**(노출계, 촬영 노트)으로 흩어져 있다. 필름 감성 앱 사용자가 실제 필름 카메라로 넘어가는 경로가 끊겨 있다.
5. **결제 피로.** 리뷰 불만의 상당수가 구독 강제·카메라별 과금. → 출시 초기엔 "무료 코어 + 깔끔한 Pro" 구조가 유리.

## 4. SILVR 차별화 전략 (5가지 핵심)

| 코드 | 차별화 | 사용자 가치 | 구현 |
|------|--------|-------------|------|
| D1 | **네거티브 보존 + 다크룸 재현상** | 찍고 나서도 필름을 바꾸고, 증감/만료/그레인을 다시 조절 | 원본(네거티브)과 현상 파라미터를 분리 저장, 비파괴 렌더 |
| D2 | **물리 기반 현상 파라미터** — Push/Pull, Expired, ISO 그레인, 할레이션 | "프리셋"이 아닌 "필름" | 필름 스톡 정의 → 톤커브 LUT + 크로스토크 매트릭스 + 셰이더 |
| D3 | **선택형 현상소** — 즉시 / 1시간 / 내일 아침 9시 / 3일 | Gudak·Dispo식 설렘을 원하는 만큼만 | 롤 상태머신 + 현상 완료 알림(앱 내) |
| D4 | **롤 단위 결과물** — 밀착 인화(Contact Sheet) 내보내기 | 한 롤을 한 장으로 SNS 공유 → 바이럴 포맷 | Canvas 합성, 필름 엣지 프린트 |
| D5 | **아날로그 컴패니언** — Sunny 16 노출 계산기 + 실제 필름 촬영 로그(CSV) | 앱 → 실제 필름 입문까지 하나로 | 순수 계산 모듈 + IndexedDB 로그 |

| D6 | **카메라 14종이 각자 다르게 동작** — 하프프레임(2번 눌러 1장), 4렌즈 연속, 이중 노출, 인스턴트 배출, 일회용 플래시 충전, 어안·아나모픽·파노라마·픽셀 | Dazz·NOMO의 "카메라 고르는 재미"를 필터가 아닌 촬영 메커니즘으로 | 카메라 모델 + 촬영 합성 + 렌즈 셰이더 |

보조 차별화: 계정·서버 없음(개인정보 0 수집), 워터마크 없음, 한/영 지원, PWA 즉시 배포 + Capacitor 스토어 빌드.

## 6. 수익화 설계 (결제 미구현, 구조만)

- 무료: 필름 9종(센서 2종 포함), 카메라 전체, 롤/현상소 전체, 컴패니언 전체, 밀착 인화, 백업.
- Pro(추후): 필름 7종 추가(Neon 800T, Velvet 50, Chrome 100 등), 즉시 현상(Rush) 무제한 등.
- 현재 빌드는 `src/entitlements.ts`의 `PAYMENTS_ENABLED = false` 로 모든 기능 개방(PRO 배지 숨김). 결제 연동 시 이 모듈만 교체.
